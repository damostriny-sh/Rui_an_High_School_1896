# 创作语法手册：一物两义的铅笔寓言

> 用途：插画创作、候选概念图与原画细读。排除项用于避免概念图重复。陶舍样板按 [ART_DIRECTION.md](ART_DIRECTION.md) 保留可辨肢体；附录的谷道措辞描述视线组织。§5 与附录 C 为 Unity 实现候选，实机规则参照技术 §10 和批准记录。保留 Git 历史中的「肢体地貌 · 符号寓言」版本。

> 样本：`fish_and_star` · `march_forward` · `redemption_pencil` · `sipping_mountain_front`
> 目标：复现的是**创作语法**（画面怎样被创造出来），不是**意象词汇**（画面里出现过什么）。
> 输出只是图像本身，不包括素描本、线圈、桌面这些拍摄环境。

---

## 0. 核心立场与生成架构

如果每次生成都出现巨物、山川和行进的人群，即使笔触和灰度很接近，也只是在模仿已经画过的东西，没有学会用这种方式创造新东西。

所以生成时，输入被拆成三个**相互独立**的部分：

```
┌──────────────────┐   ┌──────────────────┐   ┌──────────────────┐
│ STYLE GENOME     │   │ SCENE CONCEPT    │   │ EXCLUSION RULES  │
│ 风格基因         │   │ 场景概念         │   │ 排除规则         │
│ 固定，不含任何   │ + │ 每次独有：物体、 │ + │ 套路 + 近期用过  │
│ 具体意象         │   │ 作用、寓意、空间 │   │ 的意象           │
└──────────────────┘   └──────────────────┘   └──────────────────┘
                                 ↓
                         最终图像（或 Unity 场景）
```

| | 风格基因（稳定） | 意象素材（每次变化） |
|---|---|---|
| 决定 | 画面**如何**被创造 | 画面里**出现什么** |
| 内容 | 石墨灰度梯度、方向性晕擦、稚拙轮廓、一物两义、宏大尺度与空间层次、局部低饱和色彩、意象之间的作用 | 人群、山脉、手、圆规、校园、星、鱼、十字、伞、门…… |
| 输入方式 | 每次都原样输入 | 每次只输入本次概念用到的那几样 |

**附录 A 的意象素材库只在构思阶段参考，永远不直接输入给生图模型。**

## 1. 风格基因 STYLE GENOME（稳定）

这一节不包含任何具体意象。下面的举例故意每次换不同的东西，避免示例本身变成新的套路。

### 1.1 一物两义
- 画面里的关键物体，同时是另一样东西。比如一把伞是一个屋顶，一只茶杯里盛着一片海，一扇门是一个伤口。
- 意义来自物体本身的双重性，而不是靠堆砌多个符号。

### 1.2 意象之间存在作用
- **主物体只有一个**，整个画面为它服务。
- 其他物体的数量不设上限，但每一个都要同时满足四个条件：
  1. **有作用**：和主物体或者另一个物体之间，有一个说得出的动词，比如遮挡、盛着、插进、照亮、丈量。
  2. **有层级**：它有自己的灰度层级，不和主物体抢。
  3. **更弱**：它的体量和对比都弱于主物体。
  4. **不可少**：去掉它，画面就少了一层意思。否则就删掉。
- **作用要连成链，或者结成组，不要各说各话。**
- **一句话测试**：能用一句话讲清整个画面，就是清晰的；需要「……和……还有……」这样并列罗列，就是堆叠。
- **眯眼测试**：眯起眼睛看，能读出「主物体 → 其他物体 → 背景」的先后顺序。
- 同一个物体的重复算作一个。伤口或洞是物体身上的一种状态，不单独算一个。

### 1.3 宏大尺度与空间层次

**宏大感靠物体之间的关系来建立，而不是靠默认加一个小人。**下面几种方法任选其一或组合：
- **比例**：用一个大家都知道尺寸的东西做参照。比如雨滴和伞的比例、钥匙孔和门的比例、杯沿和海平线的比例。
- **透视纵深**：一点透视或者强烈的近大远小。
- **遮挡**：巨物挡住了另一个东西的大半。
- **截断**：主物体被画面边缘截断，暗示它比画面还要大，但截断后仍然要认得出来。
- **重复递减**：同一个单元一路排列下去，尺寸逐渐变小，比如雨线、台阶、门框里的门框。

**不要为了体现宏大尺度而默认添加微小的人或人群。**人只有在场景概念确实需要他时才出现，并且要在场景概念里写明理由。

**空间层次**：画面至少有前景、中景、远景三层，每层一条清楚的灰度带，层与层之间靠明度递进、前后遮挡、尺度递减来区分。

### 1.4 石墨灰度：层级分明，同时流动

| 级别 | 明度 | 用途 |
|---|---|---|
| L0 纸白 | 0.93 | 留白、亮面 |
| L1 浅灰 | 0.80 | 远景、背景块面 |
| L2 中灰 | 0.62 | 中景、次要物体 |
| L3 深灰 | 0.40 | 前景、主物体 |
| L4 纯黑 | 0.06 | 标点：一两个最关键的点 |

- 每个物体有一个自己的固有灰阶。主物体和背景至少相差两级，相邻的物体至少相差一级。
- **流动**：每个块面内部有一个顺着形体走向的渐变，晕擦也带方向，像手指顺着形体抹过去。多股这样的流最后汇向主物体。块面内部的渐变幅度不超过一级。
- 纯黑永远是黑色，不上颜色。

### 1.5 大块面与留白
- 画面由少数几个完整的大块面组成。每个块面属于一个认得出的物体，或者明确是背景。
- 留白是构图的一部分，可以占到画面的三分之一甚至更多。
- 细节只留在承担意义的地方。

### 1.6 稚拙的轮廓
- 只画外形线和物体之间的分界线，物体内部尽量不画线。
- 线条单一粗细，略微抖动，保留手画的、有点笨拙的铅笔感。不排线。

### 1.7 局部低饱和色彩
- 偶然出现，不是每张都有。有颜色的那张，也只给**一个认得出的部件**上色。
- 颜色只改变色相和饱和度，**明度完全沿用这个部件原本的灰度**，渐变、晕擦方向和纸纹都保留。
- 饱和度中等偏低，色相每张自由选择。纯黑区域不上色。

### 1.8 次要原则：主要形体的语义完整性
- 画面最重要的位置（视觉中心、面积最大的块面、对比最强处）必须由一个**叫得出名字**的东西占据。
- 巨大的、叫不出名字的抽象块面（楔形、色带、几何体）只能作为背景、留白，或者某个物体的影子，而且它的面积和对比都要弱于主物体。

### 1.9 风格基因的固定提示词块

每次生成时原样放进去。**这一段里不出现任何具体物体。**

```
[STYLE]
Graphite pencil drawing on plain paper, image only.
Values: a clear graded grey scale (paper white, light grey, mid grey, dark grey, and one or two small
areas of solid black). Every object has its own distinct grey level; the main subject is separated from
the background by a strong value step.
Flow: soft, smudged directional gradients that follow the length and direction of each form and lead
the eye toward the main subject.
Space: a monumental sense of scale built from proportion between objects, perspective depth, overlap,
and forms cropped by the frame; clear foreground, midground, and background layers.
Shapes: a few large, complete, identifiable shapes; generous empty white space; detail only where it
carries meaning.
Line: simple, slightly wobbly, naive pencil outlines on silhouettes and boundaries only; no cross-hatching.
Meaning: the key object reads as two things at once, and the objects act on each other.
```

如果这一张用颜色，就在后面追加一行：
```
Color: only [PART] is tinted in a muted, low-saturation [HUE]; its lightness follows the same graphite gradient.
```

## 2. 场景概念 SCENE CONCEPT（每次独有）

### 2.1 模板

每一张都重新填写一次，不复用上一张的内容。

| 字段 | 填什么 |
|---|---|
| 一句话寓言 | 必须通过 1.2 节的一句话测试 |
| 主物体 | 它是什么，它的第二身份是什么 |
| 其他物体 | 每个写成「物体 + 动词 + 对象」 |
| 尺度策略 | 比例、透视、遮挡、截断、重复递减，选一到两种（1.3 节） |
| 空间层次 | 前景、中景、远景各是什么 |
| 灰度分配 | 每个物体用哪一级，流向朝哪里，最后汇向哪里 |
| 纯黑落点 | 一到两处 |
| 颜色（可选） | 哪个部件，什么色相 |
| 解除的排除项（可选） | 本次需要用到哪个被排除的意象，以及**为什么非用不可** |

### 2.2 构思方法

1. **从一个日常物出发**，而不是从一个现成的符号出发，比如伞、门、茶杯、钥匙、灯泡、梯子、信封、枕头。
2. **问它的第二身份**：它像什么？它还能是什么？它在什么情况下会变成一个符号？
3. **问它作用于什么**：它遮挡、盛放、打开、照亮、丈量、吞下的是什么？
4. **选一个尺度策略**，优先选物体之间的比例，而不是加一个人。
5. **安排灰度和流向**，再决定这一张要不要颜色。
6. **对照排除规则**（第 3 节），如果和近期作品重复了，就回到第 1 步。

附录 A 的素材库可以在第 1、2 步卡住时翻一翻，但它只是启发，不是菜单。

### 2.3 示例：伞 · 雨 · 门（没有人，没有山，没有手）

| 字段 | 内容 |
|---|---|
| 一句话寓言 | 一把巨大的伞撑在一扇独立的门上方，雨只落在门的这一侧。 |
| 主物体 | 伞，第二身份是屋顶、穹顶，一种庇护 |
| 其他物体 | 门「立在」伞下，第二身份是两个世界之间的边界；雨「落在」门前，被伞「挡住」 |
| 尺度策略 | 比例：雨线的粗细和间距，让伞显得像一座穹顶；伞的边缘被画面上沿截断 |
| 空间层次 | 前景是斜落的雨线（L2 短刻线），中景是门（L3）和伞（伞面从 L3 渐变到 L2），远景是门后的大片留白（L0） |
| 灰度分配 | 雨沿下落方向由深到浅；伞面从顶部向边缘渐变；两股流在门缝处汇合 |
| 纯黑落点 | 钥匙孔 |
| 颜色（可选） | 伞的内侧，低饱和的赭黄 |
| 解除的排除项 | 无 |

**更多一句话起点（同样没有人群和山）**
- 一只茶杯里盛着整片海，杯沿就是海平线。
- 一把梯子靠在一轮月亮上，梯子的横档是尺子的刻度。
- 一枚钥匙插进一片落叶的叶脉里。
- 一盏灯泡里关着一场雪。
- 一个信封的封口是一道正在愈合的伤口。

## 3. 排除规则 EXCLUSION RULES

### 3.1 默认排除（套路）

除非在场景概念里显式解除，并且写明理由，否则下面这些都不出现：

| 排除项 | 原因 |
|---|---|
| 用来体现尺度的微小人或人群 | 最常见的套路，会自动滑向「巨物 + 小人」的公式 |
| 行进的队列、举手的人群 | 原作里出现过，最容易被反复复制 |
| 山脉、丘陵这类自然地貌 | 容易变成默认的背景 |
| 巨手、手臂堆成的地貌 | 原作里分量很重，容易被过度复用 |
| 远处的学校、城镇、建筑群 | 用来填充远景的惯性选择 |
| 「巨物 + 微小人群 + 灰色地貌」这种组合公式 | 这是风格被误读成题材之后的典型产物 |
| 星、鱼、十字 | 原作里的符号，连续使用会让作品退化成自我模仿 |
| 杂乱、互不相干的物体 | 违反 1.2 节 |
| 叫不出名字的抽象块面占据中心 | 违反 1.8 节 |

### 3.2 滚动排除（近期作品）

- 维护一份**近期作品记录**，记下每一张的主物体和尺度策略。
- **最近 3 张用过的主物体，这一张不能再用作主物体。**
- **连续 2 张用了同一种尺度策略，下一张必须换一种。**

### 3.3 解除排除

在场景概念的「解除的排除项」一栏里写明，比如：「本次使用人群，因为寓言的核心是『一个人和一群人的重量相等』，人群本身就是被称量的对象，而不是尺度参照。」**理由必须说明这个意象在寓言里承担的作用，而不能是「为了显得宏大」或者「为了填满背景」。**

### 3.4 排除规则的固定提示词块（作为负面提示词）

```
[EXCLUDE]
sketchbook, spiral binding, paper edge, frame, border, photograph of paper,
tiny people for scale, crowds, marching figures, raised hands, distant town, distant school,
mountain landscape, hills, giant hands, landscape made of body parts,
giant object with tiny people in a grey landscape,
clutter, unrelated objects, large unidentifiable abstract shapes,
cross-hatching, fully colored image, multiple colors, photorealism, text
```

解除某项排除时，从这个块里删掉对应的词，再加上这一张近期用过的主物体。

## 4. 组装：从三段到一张图

1. 填写场景概念（第 2 节）。
2. 对照排除规则（第 3 节），确认没有违规，或者已经写明解除理由。
3. 把场景概念写成**一段简短的英文描述**：只写物体、作用、尺度策略、空间层次、灰度落点。**不要写风格词，风格交给 [STYLE] 块。**
4. 组装：

```
[SCENE]
<本次的英文场景描述>

[STYLE]
<1.9 节的固定块，原样复制；如有颜色，追加 Color 行>

Negative: <3.4 节的排除块，按本次需要调整>
```

**示例（伞 · 雨 · 门）**：

```
[SCENE]
A huge open umbrella hangs over a single freestanding door; rain falls only on the near side of the door.
The umbrella is cropped by the top edge, and the thin rain lines make it read like a dome.
Foreground: slanted rain strokes. Midground: the dark-grey door and the umbrella.
Background: plain white space behind the door. The keyhole is the only solid black.

[STYLE]
...（1.9 节固定块）
Color: only the inside of the umbrella is tinted in a muted, low-saturation ochre; its lightness follows the same graphite gradient.

Negative: ...（3.4 节排除块）
```

## 5. Unity 复现流程（URP）

三段式架构在 Unity 里对应三样东西：
- **风格基因 → 渲染管线**：固定不变，所有场景共用。
- **场景概念 → 一个 `SceneConcept` 资产，加上每次单独搭建的场景**。
- **排除规则 → 编辑器检查**。

> 目标版本：Unity 6 + URP。会用到 Fullscreen Shader Graph、Full Screen Pass Renderer Feature 和 Splines。

### 5.1 风格基因 → 渲染管线

**材质：只输出数据**

| 材质 | 输出 | 用途 |
|---|---|---|
| `Tone` | 固有灰阶 + 沿 UV 走向的流动渐变 + N·L | 绝大多数物体 |
| `Void` | 纯黑遮罩 = 1 | 一两个纯黑的点 |

`Tone` 材质的参数：`baseLevel`（L0–L3）、`flowRange`（渐变幅度，不超过 0.15）、`flowCurve`（渐变曲线）、`flowInvert`（渐变方向）。模型的 UV 的 V 方向要沿着物体的走向铺开，材质用它来计算流动渐变。

**渲染数据（两张自定义 RT）**
- **RT0**：R 通道放固有灰度（已含流动），G 通道放 N·L，B 通道放纯黑遮罩，A 通道放颜色遮罩。
- **RT1**：RG 通道放屏幕空间的流动方向，B 通道放物体 ID。

**后处理顺序（Full Screen Pass Renderer Feature）**
1. 固有灰度 + 轻微的光照塑形。
2. 晕擦贴图沿流动方向拉伸采样，噪声锚定在世界空间，避免出现「浴室玻璃」效果（贴图固定在屏幕上，物体在下面滑动）。
3. 按深度把灰度推向远景灰，形成空间层次。
4. 在颜色遮罩范围内，只换色相和饱和度，明度保持不变。
5. 纯黑最后压上。
6. 轮廓线：只在固有灰阶跳变和深度跳变的地方出线，加上按帧阶梯变化的轻微抖动。
7. 乘上一层很淡的纸纹。不加边框、线圈或暗角。

**核心 Custom Function（Shader Graph，File 模式）**

```hlsl
// GraphiteTone.hlsl：灰度层级 + 流动 + 空间层次 + 保持明度的局部颜色
void GraphiteTone_float(float BaseValue, float NdotL, float LightInfluence,
                        float Smudge, float Paper, float DepthFade, float FarValue,
                        float BlackMask, float ColorMask, float3 TintColor, float TintSaturation,
                        out float3 Color)
{
    float v = BaseValue + (NdotL - 0.5) * LightInfluence;
    v += (Smudge - 0.5) * 0.08;                  // 沿流场拉伸过的晕擦
    v  = lerp(v, FarValue, DepthFade);           // 空间层次
    v *= lerp(0.95, 1.0, Paper);                 // 纸纹（很淡）
    v  = saturate(v);

    float3 tint = lerp(float3(1, 1, 1), TintColor, TintSaturation);
    float  lum  = dot(tint, float3(0.2126, 0.7152, 0.0722));
    float3 colored = saturate(tint * (v / max(lum, 1e-4)));   // 明度沿用 v
    Color = lerp(v.xxx, colored, ColorMask);

    Color = lerp(Color, float3(0.06, 0.06, 0.06), BlackMask); // 纯黑不上色
}
```

> 注意：在很亮的区域，`colored` 可能会超出 1 被截断，导致明度略微下降。如果上色的部件很亮，可以把那一段的饱和度调低。

**风格预设（ScriptableObject `GraphiteStyleProfile`）**

| 参数 | 默认值 | 说明 |
|---|---|---|
| valuePalette | 0.93 / 0.80 / 0.62 / 0.40 / 0.06 | 五级灰阶 L0–L4 |
| maxFlowRange | 0.15 | 块面内部渐变的最大幅度 |
| smudgeAmplitude / smudgeStretch | 0.04 / 3–6 | 晕擦起伏的幅度，以及沿流动方向拉伸的倍数 |
| lightInfluence | 0.08–0.2 | 光照塑形的强度 |
| depthFadeStart / End、farValue | 按场景设置 / 0.80 | 空间层次 |
| tintSaturation | 0.35–0.6 | 局部颜色的饱和度 |
| lineWidthPx | 2–3 | 轮廓线宽，在 1080p 下的像素数 |
| normalEdges | 关 | 是否画物体内部的线 |
| boilFPS / boilAmp | 10 / 0.0015 | 线条抖动的频率和幅度 |

### 5.2 场景概念 → `SceneConcept` 资产

每个场景挂一个 `SceneConcept`（ScriptableObject），字段就是 2.1 节的模板：一句话寓言、主物体、其他物体（物体、动词、对象）、尺度策略（枚举：比例、透视、遮挡、截断、重复递减）、空间层次、颜色部件、解除的排除项和理由。

场景里的物体挂 `MotifTag` 组件，字段包括：角色（主 / 其他）、作用对象、作用动词、类别标签。类别标签用于排除检查，比如 `Crowd`、`Mountain`、`GiantHand`、`BodyTerrain`、`Town`、`Star`、`Fish`、`Cross`。

**资产只为本次概念建模**，不预先建一个大而全的意象资产库。做好的资产可以留着，但不作为构思的出发点。

### 5.3 排除规则 → 编辑器检查

| 检查项 | 标准 |
|---|---|
| 默认排除 | 场景里出现被排除类别的 `MotifTag`，而 `SceneConcept` 里没有声明解除 → 报错 |
| 解除理由 | 声明了解除但理由为空 → 报错 |
| 滚动排除 | 主物体和最近 3 张中的任意一张相同 → 报错；尺度策略和最近 2 张都相同 → 警告 |
| 主物体 | 标记为「主」的恰好 1 个 |
| 作用 | 每个其他物体都填了作用对象和作用动词，所有物体能连成一个整体 |
| 层级 | 其他物体的画面面积和灰度对比都小于主物体 |
| 灰度对比 | 主物体和背景至少相差两级，相邻物体至少相差一级 |
| 空间层次 | 至少三个明显不同的深度层 |
| 留白 / 纯黑 | 纸白占 25% 以上，纯黑占 5% 以下 |
| 颜色 | 上色的部件不超过 1 个；上色前后，平均明度差小于 0.02 |
| 语义完整性 | 画面中心和最大块面所属的物体，必须带 `MotifTag` |

近期作品记录用一个 `ConceptHistory` 资产保存：每次场景定稿，就把它的主物体和尺度策略追加进去。

## 附录 B：原作细读（作为参照，不是模板）

- `redemption_pencil`：两支铅笔交叉成十字，同时也是准星；手握着十字，而不是被钉在上面；画者的手出现在画里，形成自我指涉。构图是单体圣像式：居中、孤立、只有一个背景圆盘。它最清楚地示范了「一物两义」。
- `sipping_mountain_front`：一点透视的谷道，加上层层叠叠的流动带，示范了空间层次和灰度流动。
- `fish_and_star`、`march_forward`：示范了宏大尺度和对角线的动势。同时它们也提醒我们：中央那种叫不出名字的抽象块面，以及成片的人群，正是现在需要警惕的地方。

## 附录 C：身体地貌生成器（可选 Unity 模块）

只有当场景概念**明确需要**身体地貌，并且已经在排除规则里声明解除时才使用。

| 方式 | 工具 | 适合的地貌 |
|---|---|---|
| 沿线排列 | Splines 包的 SplineInstantiate 组件 | 山脊线、海岸线 |
| 叠层挤出 | 多条平行的 SplineExtrude | 地层、梯田 |
| 区域散布 | 自己写的泊松圆盘散布脚本 + `Graphics.RenderMeshInstanced` | 森林、圆石滩 |
| 高度图 | 指纹或掌纹转成高度图，导入 Unity Terrain | 等高线地形 |

主要参数：`layerValues`（每层的灰阶）、`flowAlongBody`（渐变沿身体走向）、`scaleByDistance`、`variation`、`flowField`、`burialDepth`、`revealCount`（默认 1）、`seed`。

## 创作时的自问

- 这一张的主物体，**最近 3 张用过吗**？
- 宏大感是靠什么建立的？**是不是又偷偷加了一个小人？**
- 去掉风格（灰度、线条），只看场景描述，它和以前的作品像吗？
- 能用一句话讲完整个画面吗？
- 主物体同时是什么别的东西？
- 能看出前景、中景、远景吗？灰度在流动吗？流向哪里？
- 画面中心那个形体叫得出名字吗？
- 如果用了颜色：是不是只有一个部件？去掉颜色之后，灰度看起来还一样吗？
